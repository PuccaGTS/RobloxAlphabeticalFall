# Буквопад / AlphabetFall

Обучающая игра для Roblox: ребёнок 4–7 лет изучает русский алфавит от **А** до **Я**,
проходя испытания, зарабатывая валюту и покупая косметику для персонажа.

**Рабочее название:** «Буквопад: Азбучные острова» (EN: *AlphabetFall*)
**Платформа:** Roblox (PC, планшет, телефон — приоритет **тач**)
**Аудитория:** 4–7 лет, играет часто вместе с родителем
**Язык контента:** русский (озвучка — обязательна, текст — вспомогателен)

---

## Одна фраза о концепции

Ребёнок выходит из портала на большом спавне, бежит по дороге с препятствиями,
на воротах выбирает нужную букву или ответ на пример, добегает до сохранки —
и возвращается домой строить свой дом за заработанные Звёздочки.

## Ключевые проектные решения (кратко)

1. **Голос важнее текста.** Любая инструкция сначала звучит, потом показывается иконкой,
   и только потом (опционально) текстом. Игра проходима ребёнком, который не читает вообще.
2. **Нет проигрыша.** Испытание нельзя провалить — можно только пройти медленнее.
   Ошибка = мягкий звук + подсказка, никогда не «красный крест» и не потеря прогресса.
3. **Микрофон — бонус, а не основа.** См. [06-MICROPHONE.md](docs/06-MICROPHONE.md).
4. **Валюта одна и только зарабатываемая.** Звёздочки нельзя купить за Robux.
   За Robux продаётся только косметика и удобства, не прогресс и не обучение.
5. **Никакой случайности за деньги.** Лутбоксов/рулеток нет вообще — аудитория детская.
6. **Сессия 10–20 минут.** Игра сама предлагает паузу и хвалит за остановку.
