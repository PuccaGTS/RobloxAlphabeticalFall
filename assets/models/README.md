# Модели

Сюда кладутся модели, которые попадают в игру. Rojo синхронизирует эту папку
в `ReplicatedStorage.Assets`, дальше их разбирают сервисы.

- `decor/` — декор площади: деревья, клумбы, лавочки, фонтан.
  Каталог и точки расстановки — `src/shared/Config/Decor.luau`,
  ставит их `src/server/Services/DecorService.luau`.

Полная инструкция «как добавить модель» — [docs/21-DECOR.md](../../docs/21-DECOR.md).

Коротко: экспортировать модель из Studio как `.rbxm`, назвать файл ровно так же,
как `id` предмета в каталоге, положить в нужную подпапку, перезапустить `rojo serve`.
