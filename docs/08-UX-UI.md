# 08 — UX/UI для ребёнка, который не читает

## 1. Главное правило

**Игра должна быть полностью проходима ребёнком, который не умеет читать ни одного слова.**
Проверка на каждом экране: закрой весь текст — экран остаётся понятным? Если нет — переделать.

Порядок подачи любой информации:
```
1. ГОЛОС (всегда)  →  2. ИКОНКА/АНИМАЦИЯ (всегда)  →  3. ТЕКСТ (дублирование, опционально)
```

## 2. Правила интерфейса

| Правило | Значение | Почему |
|---|---|---|
| Минимальный размер кнопки | **80×80 px** (на 1080p), не менее 12% высоты экрана на телефоне | палец ребёнка неточен |
| Расстояние между кнопками | ≥ 24 px | защита от промаха |
| Одновременно активных элементов | **не более 3** | ребёнок 5 лет не сканирует экран |
| Текст на кнопке | иконка обязательна, текст — опционален | не читает |
| Шрифт | крупный, рубленый, ≥ 28 pt, **высокая контрастность** | |
| Начертание букв | **печатные, как в букваре**, без засечек, «а» и «т» в детском варианте | ребёнок должен узнать эту же букву в книге |
| Анимация подсказки | пульсация 1 Гц на нужном элементе через 8 с бездействия | ведёт без слов |
| Отмена | всегда есть «домик» в углу, одинаковый на всех экранах | не должен застревать |
| Модальные окна | максимум 1, с одной главной кнопкой | |

## 3. Постоянный HUD

```
┌──────────────────────────────────────────────┐
│ [🏠]                    ⭐ 245        [⚙]     │
│                                              │
│                                              │
│               ИГРОВОЕ ПОЛЕ                   │
│                                              │
│  [🔊]                              [🎒]      │
│                            ┌─────────────┐   │
│  джойстик                  │   прыжок    │   │
└──────────────────────────────────────────────┘
```

- **🔊 «Повтори»** — самая важная кнопка. Всегда на экране, всегда в одном месте,
  всегда работает. Повторяет последнюю значимую реплику.
- **⭐ Счётчик звёздочек** — с анимацией прилёта при начислении (это главный дофамин).
- **🎒 Рюкзак/гардероб** — вход в косметику.
- **🏠 Домой** — телепорт в хаб, доступен из любого испытания без штрафа.
- **⚙ Настройки** — громкость, субтитры, **родительский режим** (за PIN).

Ничего больше. Никаких новостей, баннеров, промо-акций, счётчиков онлайн.

## 4. Как выглядит буква

Единый визуальный стандарт (нарушать нельзя — от него зависит перенос знания в книгу):

- **Печатная заглавная**, строгая форма из букваря, без декоративных завитков.
- Толстая, объёмная, скруглённая — приятно «поймать».
- **Цвет по виду буквы** (постоянная кодировка во всей игре):
  - 🔴 **красный** — гласные (А, Е, Ё, И, О, У, Ы, Э, Ю, Я)
  - 🔵 **синий** — согласные и шипящие
  - ⚪ **серый** — Ь и Ъ

  Это стандартная схема из российских букварей — ребёнок встретит её же в школе.
  Цвет здесь остался от прошлой концепции и работает как узнаваемая примета формы,
  а не как подсказка про звук: звуков игра не даёт вовсе.
- **Глаза** — две точки, моргают. Это делает букву персонажем и снижает тревожность.
- **Строчная версия** показывается рядом мелко (`Мм`) начиная с четвёртой ступени, без требования.

## 5. Обратная связь

| Событие | Визуал | Звук | Голос |
|---|---|---|---|
| Правильно | буква подпрыгивает, вспышка звёзд, +1 к счётчику | звон вверх | «Молодец!» (1 из 8 вариантов) |
| Неправильно | буква мягко качается «нет», уходит вниз | тихий «пуф» | «Почти! Это буква П, а нам нужна буква М» |
| Подсказка | нужный объект пульсирует и светится | лёгкий «динь» | «Смотри сюда» |
| Награда | ⭐ летят к счётчику по дуге | россыпь | «Ты заработал десять звёздочек!» |
| Новая буква освоена | буква летит в Башню, сегмент зажигается, салют | фанфары (короткие!) | «Буква М теперь твоя!» |

**Запрещено:** красный цвет ошибки, крестики, звук «неудача», тряска экрана,
надпись «неправильно», уменьшение счётчика.

## 6. Экраны

1. **Загрузка** — Азбука машет, прогресс-бар в виде выкладываемых букв.
2. **Хаб** — Башня в центре, пады занятий по кругу, магазин, гардероб.
   Свободное перемещение, карты и меню нет.
3. **Башня прогресса** и есть карта: 33 сегмента снизу вверх, серые — незнакомые,
   светящиеся — твои. Ребёнок видит не «уровень 4 из 11», а сколько букв уже его.
4. **Испытание** — минимум UI: цель вверху, счётчик, 🔊, 🏠.
5. **Итог испытания** — 1–3 звезды, ⭐ прилетают, две кнопки: «Ещё раз» и «Домой».
6. **Магазин** — крупные карточки-предметы 3×2, цена ⭐ цифрой + звёздочками (чтобы
   было понятно и без знания цифр), кнопка «Примерить» больше кнопки «Купить».
7. **Гардероб** — персонаж по центру, вращение пальцем, категории иконками слева.
8. **Башня прогресса** — 33 сегмента; тап по букве → она произносит себя (бесплатное
   повторение, без испытания). Отличный «музей достижений».
9. **Родительский режим** — единственный экран с настоящим текстом для взрослых.

## 7. Туториал

- Никаких обучающих текстов. Только: голос + стрелка + пульсация + рука-указатель.
- Обучаем по одному действию за раз, каждое закрепляем сразу.
- Управление даётся **в движении**, а не на экране с описанием клавиш.
- Пропустить туториал нельзя ребёнку, но можно в родительском режиме
  (для второго ребёнка в семье).

## 8. Доступность

- **Субтитры** (для читающих старших и родителей) — переключаются в настройках, по умолчанию **выкл**.
- Полностью проходимо **без звука**? Нет — и это осознанно: озвучка это суть игры.
  Но: любая обучающая реплика дублируется анимацией артикуляции и подсветкой цели,
  так что ребёнок с тугоухостью может играть, хоть и с меньшей пользой.
- Учёт дальтонизма: цветовая кодировка букв **всегда дублируется формой/иконкой**
  (гласные — с «лучиками», согласные — гладкие).
- Никакого мигания чаще 3 Гц (риск фотосенситивности).
- Крупный режим UI (×1.25) в настройках.

## 9. Тон общения

- Обращение на «ты», по-доброму, без сюсюканья и без уменьшительных в каждом слове.
- Хвалим **действие**, а не ребёнка: «Ты нашёл букву М!», а не «Ты умница».
- Никогда не говорим «неправильно», «ошибка», «ты не смог».
- Не торопим: «У тебя есть время», «Подумай».
- Прощаемся тепло и зовём завтра: «Приходи завтра, буквята будут скучать!»
