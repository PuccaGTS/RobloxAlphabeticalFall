# 05 — Озвучка и звук

Озвучка — **не украшение, а основной канал обучения**. Ребёнок 4–7 лет не читает,
поэтому всё, что игра хочет сказать, она говорит вслух.

## 1. Голос

- **Один основной диктор** — женский, тёплый, неспешный, без сюсюканья.
  Персонаж: **Азбука** — добрая наставница, живёт в Башне.
- **Второй голос (опционально, релиз 1.0)** — детский/мультяшный, для буквят.
  Буквята произносят **свою букву**, диктор говорит инструкции. Разделение важно:
  ребёнок должен отличать «объяснение» от «эталона для повтора».
- Темп: **на 15–20% медленнее обычной речи**. Между инструкцией и вопросом — пауза 0.8 с.
- Никакого эха/реверба на обучающих репликах — только чистый голос.

## 2. Категории реплик и объём

| Категория | Префикс | Кол-во | Пример содержимого |
|---|---|---:|---|
| Звук буквы (изолированно) | `snd_` | 33 | «м-м-м», «а-а-а», «с-с-с» |
| Звук, растянутый для эха | `snd_long_` | 20 | только тянущиеся: гласные, М,Н,Л,Р,С,З,Ш,Ж,В,Ф,Х,Щ |
| Название буквы (остров 8) | `name_` | 33 | «эм», «ша», «мягкий знак» |
| Слог-слияние | `blend_` | ~180 | «мммм-а» → «МА» **записывается слитно**, не склеивается |
| Слово | `word_` | 60 | «кот», «дом», «луна» |
| Слово по слогам | `word_syl_` | 60 | «ко-от», «до-ом» |
| Инструкция испытания | `instr_` | ~40 | «Лови букву М!», «Иди только по букве О!» |
| Похвала | `praise_` | 25 | «Молодец!», «Точно!», «Вот это да!», «Ты справился!» |
| Мягкая коррекция | `retry_` | 20 | «Почти! Слушай ещё раз», «Это П. А нам нужна М» |
| Подсказка | `hint_` | 20 | «Смотри, буква светится», «Попробуй вот эту» |
| Сюжет/навигация | `story_` | 50 | вступление, переходы островов, боссы |
| UI/системные | `ui_` | 40 | «Магазин», «Твои звёздочки», «До завтра!» |
| Родительский режим | `parent_` | 15 | реплики для взрослого |
| **Итого** | | **~600** | |

**Приоритет записи:**
1. Сессия 1 (MVP): `snd_` (6 гласных + М,П,Б), `blend_` для них (~24), `instr_` (3),
   `praise_` (8), `retry_` (5), `story_` вступление (6). **≈ 60 реплик.**
2. Сессия 2: остальные `snd_`, все `blend_`, `word_`.
3. Сессия 3: `name_`, `story_`, `parent_`, расширенные похвалы.

## 3. Технические требования к записи

| Параметр | Значение |
|---|---|
| Формат мастера | WAV 48 кГц, 24 бит, моно |
| Формат загрузки в Roblox | OGG или MP3, 44.1/48 кГц (Roblox перекодирует сам) |
| Уровень | нормализация до −3 dBFS peak, целевая громкость ≈ −16 LUFS |
| Тишина | 100 мс в начале, 250 мс в конце — **обязательно**, иначе обрыв слова |
| Шум | пол шума ниже −60 dB, комната без эха, поп-фильтр |
| Длина файла | звук буквы ≤ 1.5 с, слог ≤ 2 с, инструкция ≤ 5 с |
| Один файл | одна реплика. Никаких «нарезок» на клиенте |

⚠️ **Не склеивать слоги из отдельных букв в рантайме.** «М» + «А» на движке звучит как
«м. а.» и учит ребёнка неправильному, побуквенному чтению. Каждый слог — отдельная запись.

## 4. Именование ассетов

```
vo_ru_<категория>_<ключ>_v<версия>.wav

Примеры:
vo_ru_snd_m_v1.wav
vo_ru_snd_long_s_v1.wav
vo_ru_blend_ma_v1.wav
vo_ru_word_kot_v1.wav
vo_ru_instr_catch_letter_v2.wav
vo_ru_praise_01_v1.wav
```

Ключ буквы — **латиницей по транслиту**, фиксированная таблица (см. [09-DATA-SCHEMA.md](09-DATA-SCHEMA.md)):
`a u o i y e m p b t d n k g h v f s z l r j sh zh ch shch c ye yo yu ya soft hard`

## 5. Аудио-архитектура в игре

**Шины (SoundGroup):**

```
Master
├── VO        (озвучка)        приоритет наивысший
├── SFX       (эффекты)
├── Music     (фон)
└── Ambient   (окружение)
```

**Правило дакинга:** при воспроизведении любого `VO` громкость `Music` и `Ambient`
опускается до **30%** за 150 мс и возвращается через 300 мс после окончания.
Реализуется через `TweenService` на `SoundGroup.Volume`. Это требование, а не пожелание:
без него ребёнок не разберёт звук буквы.

**Очередь VO:** реплики не накладываются. Менеджер держит очередь; новая реплика
высокого приоритета (`instr`) прерывает низкую (`ui`), но никогда не прерывает `snd_`/`blend_` —
эталон звука должен доигрываться всегда.

**Предзагрузка:** `ContentProvider:PreloadAsync` для всех реплик текущего острова
на экране загрузки. Задержка перед звуком буквы недопустима.

**Кнопка «повторить»:** всегда воспроизводит последнюю реплику из категории
`snd_/blend_/instr_`. Кулдаун 0.5 с, чтобы не было каши при спаме.

## 6. Музыка и эффекты

- **Музыка:** спокойная, 60–80 BPM, инструментальная, лупы по 60–90 с, отдельная тема
  на остров. В испытаниях — тише на 40%.
- **SFX-словарь:** поймал (звон+вверх), ошибся (мягкий «пуф», без диссонанса),
  награда (звёздная россыпь), покупка (касса-колокольчик), шаг, прыжок, открытие сундука.
- **Запрещено:** резкие удары, низкочастотный «бум», сирены, звук проигрыша.
  Ошибка звучит **нейтрально**, а не негативно.

## 7. Загрузка в Roblox — что нужно знать

- Аудио загружается через Creator Dashboard, проходит **модерацию** (обычно минуты–часы,
  но закладывайте до суток). Загружайте пачками **заранее**, не в день релиза.
- Загруженное аудио по умолчанию **приватно** — используйте его в опыте, принадлежащем
  тому же аккаунту/группе, что и аудио. **Всё загружаем на аккаунт группы**, не на личный,
  иначе потом не передать права.
- Есть лимиты на количество загрузок в сутки — планируйте сессии загрузки.
- Каждый `assetId` фиксируем в таблице соответствия `vo_key → rbxassetid` (см. [10-CONTENT-PIPELINE.md](10-CONTENT-PIPELINE.md)).
  Никогда не пишем сырые ID в коде испытаний — только через реестр.

## 8. Резервный вариант на время прототипа

Пока нет живого диктора — используем синтез речи (любой качественный русский TTS)
как **временную заглушку**, помечая файлы суффиксом `_tts`. Правила:
- TTS **не идёт в релиз** — детская обучающая игра требует живого голоса,
  особенно для изолированных звуков (TTS плохо произносит «м-м-м» вне слова).
- Все TTS-файлы обязаны быть перезаписаны до 1.0. Ведём чек-лист замены.
- Проверяйте лицензию используемого TTS на коммерческое применение.
