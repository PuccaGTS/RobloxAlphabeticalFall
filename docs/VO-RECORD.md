# Лист записи озвучки — 70 реплик

Читать сверху вниз, подряд, одной дорожкой. Между репликами — пауза 2 секунды.
Ошибся — не останавливайся: пауза и повтори реплику целиком, потом выберем лучший дубль.

Слева — имя файла (так потом назвать кусок: `letter_a.wav`), справа — что сказать.
Полный справочник с пояснениями — [VO-SCRIPT.md](VO-SCRIPT.md), как записывать —
[20-VO-SESSION-1.md](20-VO-SESSION-1.md), технические требования — [05-AUDIO-VO.md](05-AUDIO-VO.md) § 3.

Список сверен с игрой 25.09.2026: это ровно то, что игра просит и чего у неё нет.

**Время:** около 20 минут записи, ещё час на нарезку в Audacity.

---

## Перед началом (2 минуты)

- Телефон в авиарежим, холодильник и вытяжку выключить.
- Микрофон в 15–20 см, чуть сбоку от рта.
- WAV, 48 кГц, моно. Без эффектов и без изменения голоса.
- Первые 5 секунд — тишина: по ней потом снимается шум комнаты.

## 5. Куски математических заданий — 13

Тоже ровно: после большинства кусков игра подставит число. Голос в конце **не опускать**,
кроме трёх полных фраз — они помечены «конец».

| № | Файл | Сказать | После неё |
|--:|---|---|---|
| 58 | `mtask_where` | Беги туда, где | число |
| 59 | `mtask_digit` | Беги на цифру | число |
| 60 | `mtask_more` | Беги туда, где больше | конец |
| 61 | `mtask_less` | Беги туда, где меньше | конец |
| 62 | `mtask_howmuch` | Сколько будет | число |
| 63 | `mtask_missing` | Сколько не хватает, чтобы стало | число |
| 64 | `mtask_total` | Сколько всего? | конец (звучит после «три по два») |
| 65 | `mop_plus` | плюс | число |
| 66 | `mop_minus` | минус | число |
| 67 | `mop_by` | по | число |
| 68 | `mtask_collect` | Собери ягод: | число |
| 69 | `mtask_collect_that` | Собери столько ягод и отнеси в корзинку. | конец |
| 70 | `mtask_fill` | Доложи ягод, чтобы в корзинке стало | число |

Как куски складываются в игре:

```
Сколько будет + два + плюс + два             →  «Сколько будет два плюс два»
Беги на цифру + семь                         →  «Беги на цифру семь»
три + по + два + Сколько всего?              →  «Три по два. Сколько всего?»
Доложи ягод, чтобы в корзинке стало + пять   →  «Доложи ягод, чтобы в корзинке стало пять»
```

## После записи

1. Нарезать в Audacity по меткам с именами из таблиц, экспортировать пачкой в `music/Реплики`.
2. `python tools/audio/prepare_vo.py` — обработка, файлы лягут в `music/Готовое/vo`.
3. Послушать П, Б, Т, Д, К, Г подряд — должны различаться.
4. Загрузить на аккаунт группы Roblox, номера — в `assets/audio/MANIFEST.csv` и `AudioRegistry.luau`.
