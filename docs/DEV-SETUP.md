# DEV-SETUP — как запустить проект

## 0. Что нужно установить (Windows)

**Минимум, чтобы увидеть игру:**

1. **Roblox Studio** — сама среда, где всё запускается. Нужен аккаунт Roblox.
   ```
   winget install --id Roblox.RobloxStudio
   ```
2. **Rojo** — синхронизирует файлы из репозитория в Studio.
   ```
   winget install --id Rojo.Rojo
   ```
3. **Плагин Rojo для Studio** — ставится самой Rojo одной командой:
   ```
   rojo plugin install
   ```

**Дополнительно (для тестов и удобства):**

- **Rokit** (`winget install --id Rojo.Rokit`) — менеджер инструментов: поставит `wally`,
  `stylua`, `selene`, `luau-lsp`, `run-in-roblox` нужных версий одной командой `rokit install`.
  Если ставишь Rokit, отдельная установка Rojo не нужна — он придёт из `rokit.toml`.
- **VS Code** + расширения **Luau Language Server** и **StyLua**.

## 1. Инструменты через Rokit

```bash
rokit install
```

Ставит всё из `rokit.toml`. Если Rokit ругается, что версии нет, — обнови её
командой `rokit add <имя-инструмента>`.

Зависимости Luau (нужны только для тестов — там лежит TestEZ):

```bash
wally install
```

Появятся папки `Packages/` и `DevPackages/` — они в `.gitignore` и в репозиторий не идут.
Для запуска самой игры они не требуются.

## 2. Запуск в Roblox Studio

```bash
rojo serve
```

В Studio открыть собранное место `build/AlphabetFall.rbxl` (как собрать — ниже),
вкладка **Plugins** → **Rojo** → **Connect**. Шаблоны из **New** не годятся: у них
свой рельеф и объекты поверх площади. Игра при запуске их убирает, но смотреть
на это незачем.
Дальше **Play** — и правим файлы в редакторе, Studio обновляется сам.

**Про сохранения:** без публикации места DataStore недоступен, и профиль работает
в памяти — прогресс не переживёт перезапуск, это ожидаемо и в логе об этом написано.
Чтобы сохранения заработали по-настоящему: опубликовать место
(File → Publish to Roblox) и включить Game Settings → Security → **Enable Studio Access
to API Services**.

Собрать место в файл:

```bash
rojo build -o build/AlphabetFall.rbxl
```

## 3. Тесты

```bash
rojo build test.project.json -o build/test.rbxl
```

```bash
run-in-roblox --place build/test.rbxl --script tools/TestRunner.server.luau
```

**Стенки туннеля** — после правок трассы (TrackShape, TunnelService.buildCorridor):

```bash
rojo build default.project.json -o build/game.rbxl
run-in-roblox --place build/game.rbxl --script tools/TunnelGuardCheck.server.luau
```

В выводе у каждого сида должно быть `gaps 0 intrusions 0`.

**Если `run-in-roblox` пишет «Timeout reached while waiting for Roblox Studio»
или «Не удаётся найти указанный файл»:** скорее всего Studio обновилась, а путь
к ней в реестре (`HKCU\Software\Roblox\RobloxStudio\ContentFolder`) остался
от удалённой версии. Лечится так: запустить Studio вручную, дать ей открыться
и закрыть по-нормальному — на выходе она чинит запись сама. После этого тесты идут.

| `tests/ParentReportText.spec.luau` | отчёт словами: склонения, время, полоска, строки по буквам, без угадывания пола ребёнка |

`ConfigIntegrity` — самый важный: он ловит ошибки, которые иначе всплывут на ребёнке
(пропущенная буква алфавита, ступень из чужих букв, буква без озвучки,
ссылка на несуществующее испытание). Он же держит потолок объёма записи:
не больше сотни реплик, потому что именно объём озвучки однажды уже сменил концепцию.

## 5. Структура

```
src/shared    → ReplicatedStorage.Shared    конфиги, чистая логика, типы, Remote-реестр
src/server    → ServerScriptService.Server  источник истины: прогресс, экономика, испытания
src/client    → StarterPlayerScripts.Client презентация: звук, UI, ввод
tests         → ReplicatedStorage.Tests     только в test.project.json
tools         → утилиты разработки, в прод-сборку не попадают
```

Полное описание архитектуры — [07-TECH-ARCH.md](07-TECH-ARCH.md).

## 6. Что сделано и что дальше

**Готово:**
- Rojo-скелет, линтеры, Wally.
- `Config/Letters` — все 33 буквы: название, место в алфавите, ступень, цвет, пары-путаницы.
- `Config/Stages` — 11 ступеней по три буквы, строго по алфавиту.
- `Config/Obstacles`, `Config/Tunnel` — каталог элементов полосы (пять базовых
  и пять средних) и геометрия забегов.
- `Config/Challenges`, `Config/Economy` — все числа вынесены из кода.
- `Config/AudioRegistry` — реестр озвучки; пока пустой, игра это переживает и пишет в лог.
- `Logic/MasteryRules`, `Logic/ReviewScheduler`, `Logic/DifficultyCurve` — чистые, с тестами.
- `Net/RemoteDefs` — единый реестр Remote'ов с лимитами частоты.
- `AudioController` — очередь озвучки, приглушение музыки на время реплики, кнопка «повторить».

- Слой данных: `DataBackend` (DataStore с сессионной блокировкой и ретраями, в Studio —
  память), `ProfileService` (загрузка, автосохранение раз в минуту, выгрузка, BindToClose),
  `ProfileTemplate` + `Logic/Migrations` с тестами.
- `EconomyService` — единственная точка начисления Звёздочек, с часовым потолком
  и белым списком источников.
- `ProgressService` — применение ответов: статусы букв, планирование повторений,
  открытие ступеней, адаптивная сложность, заказ наград.

- `ChallengeService` + модули испытаний (`LetterRain`, `AlphabetLadder`, `RunCourse`
  с обёртками `TunnelRun` и `ObstacleCourse`): сервер строит задание, валидирует
  каждое действие по своему времени, начисляет награду.
- `TunnelService` — геометрия забегов: коридор, ворота, препятствия, сохранки,
  мягкое дно и возврат к последней точке при падении. Пройденная арка уходит
  в профиль, и незаконченный забег продолжается в следующий заход
  (`RunCourse.Rebuild`, docs/09-DATA-SCHEMA.md § 8.2).
- `RateLimiter` — лимиты частоты на Remote'ы.
- Клиент: `ChallengeController` (падающие буквы без физики, тапы, обратная связь)
  и серый HUD (счётчик ⭐, буква-цель, кнопка «динамик»).

- `Challenges/AlphabetLadder` + `LadderController` — «Алфавитная лестница»: подъём
  идёт по соседним буквам алфавита, промах не убирает выбор и не двигает ступень.
- `ShopService` + `CosmeticsService` + `Config/Shop` — 12 предметов, покупка,
  гардероб, сборка косметики из примитивов и приварка к персонажу.
- `WorldService` — площадь: два портала в центре («Мир букв» открыт, «Мир математики»
  закрыт до ворот с числами), точка появления между ними, полукруг из трёх падов
  занятий и магазина, дорожки к кольцу участков.
- `BaseService` + `Config/Base` — двадцать участков по краю площади: дом, крыша, двор
  и забор по четыре уровня, покупка на своём участке по подсказке с удержанием,
  свободный участок с колышками у тех, кто ещё не зашёл.
- `TowerController` — Азбучная Башня на клиенте: 33 сегмента по статусам букв,
  тап по сегменту называет букву. Стоит во дворе хозяина: место приходит с сервера
  вместе с участком (`BaseAssigned`).

**Как проверить руками:** `rojo serve` → Play в Studio.

1. Игрок появляется на площади: перед ним два портала, вокруг пады занятий,
   по краю — кольцо домов, среди которых его собственный с Башней во дворе.
2. Пад «Буквопад» → **Ловить**: ловим целевую букву, промах притушивает буквы на секунду.
3. Заработать 10 ⭐ → пад магазина или кнопка 🛍 → купить кепку. Она сразу надевается.
4. Тапнуть по сегменту Башни — сегмент назовёт свою букву (сейчас молча).
5. Пад «Алфавитная лестница» → выбираем следующую букву алфавита.
6. Пад «Азбучный туннель» и «Полоса препятствий» → забег с воротами, препятствиями
   и сохранками. Подробный сценарий — [HOW-TO-CHECK.md](HOW-TO-CHECK.md).

Озвучки нет — будет тишина и предупреждения в логе. Это ожидаемо.
