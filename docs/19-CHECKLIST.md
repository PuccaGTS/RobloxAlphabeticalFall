## 0. Как пользоваться

Работа идёт **пятью параллельными треками**. Они почти не блокируют друг друга,
кроме одного места: без звука половина механик не проверяется.

| Трек | Кто нужен | Блокирует |
|---|---|---|
| 💻 Код | программист | всё |
| 🔊 Аудио | диктор + монтаж | проверку обучающих механик |
| 🎨 Арт | художник или ассет-пак | ничего, но без него игра «серая» |
| 📚 Контент | методист/дизайнер | уровни |
| 🧪 Проверка | дети и родители | решение «идём дальше или переделываем» |

Обозначения приоритета: 🟢 первая версия · 🟡 релиз 1.0 · 🔵 после релиза.

- [ ] Раскрыта в Explorer, внутри **нет** `Script` и `LocalScript`
- [ ] Нет `require(<число>)`, `getfenv`, `HttpGet`, `loadstring`
- [ ] Автор с историей, а не свежий аккаунт с бесплатным паком

- [ ] Загружено на аккаунт группы

> Правило: **меши и текстуры — можно, скрипты — никогда.**

```
6. Уровни 1–4 мира букв

```

Пункты 2 и 3 можно вести параллельно: аудио не зависит от кода.

## 9. Когда задача считается сделанной

| Тип задачи | Готово, когда |
|---|---|
| Код-фича | работает в Studio, покрыта тестом, начисления на сервере, ошибок в Output нет |
| Уровень | пройден ребёнком без помощи взрослого от начала до финиша |
| Реплика | записана, обработана, загружена, ID в реестре, слышно на телефоне |
| Ассет | загружен на группу, проверен на скрипты, вписан в манифест, укладывается в бюджет |
| Механика обучения | ребёнок узнаёт букву через 3 дня после занятия |

Последняя строка — единственная, которая по-настоящему важна.
Всё остальное существует ради неё.
