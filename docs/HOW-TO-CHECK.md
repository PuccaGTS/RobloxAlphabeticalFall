# Как запустить и проверить

Пошаговый сценарий приёмки вертикального среза. Проходится за 10 минут.
Установка инструментов — [DEV-SETUP.md](DEV-SETUP.md) § 0.

---

## 1. Запуск

**Шаг 1.** Открыть новую консоль PowerShell и поднять синхронизацию:

```bash
cd D:\RobloxAlphabeticalFall; rojo serve
```

Консоль должна написать `Rojo server listening on port 34872` и остаться висеть.
**Не закрывай её** — пока она работает, правки файлов уезжают в Studio сами.

**Шаг 2.** Собрать чистое место и открыть его в Studio (двойной клик по файлу
или **File → Open**):

```bash
cd D:\RobloxAlphabeticalFall; rojo build -o build/AlphabetFall.rbxl
```

Открывать **`build/AlphabetFall.rbxl`**, а не шаблон из **New**: шаблоны Studio
приносят свой рельеф с травой, горы и витрины. Игра при запуске их убирает
(в Output строка `[World] убрано чужое из Workspace`), но чистое место
открывается быстрее и ничем не отвлекает.

**Шаг 3.** В Studio: вкладка **Plugins** → **Rojo** → **Connect** (адрес `localhost:34872`).

**Шаг 4.** Открыть панель логов: **View → Output**. Без неё половина проверок вслепую.

**Шаг 5.** Нажать **Play** (F5). Остановка — **Shift+F5**.

> Скрипты запускаются **только в Play**. В режиме редактирования Output пустой — это нормально.

## 2. Что должно быть в Output сразу после Play

```
[AlphabetFall] контент: букв 33, ступеней 11, препятствий 10
[AlphabetFall] озвучка не загружена для N из M реплик — игра работает молча
[Decor] расставлено 28 предметов; моделей нет для 8 видов — стоят эскизы
[World] площадь построена: порталов 2, падов 4, букв 33
[Safety] чат выключен
[AlphabetFall] сервер запущен
[ProfileService] профиль загружен: <ник> (звёздочек: 0)
[AlphabetFall] клиент запущен
```

Плюс предупреждение, что прогресс не сохраняется между сессиями — так и должно быть,
пока место не опубликовано.

Строка `[Decor] в модели "…" было N скриптов — они удалены` означает, что в чужой
модели лежал чужой код. Он уже вырезан, но модель стоит перепроверить —
[21-DECOR.md](21-DECOR.md) § 4.

Значка чата в верхней панели нет, клавиша `/` окно чата не открывает.
Строка `[Safety] найден канал чата … — удалён` значит, что в настройках места
снова включены каналы по умолчанию: чата всё равно нет, но галочку стоит снять.

**Красных ошибок быть не должно.** Если есть — скопировать текст целиком, это баг.

## 3. Сценарий проверки

### 3.0. Панель разработчика 🛠

В Studio (и у владельца места на сервере) слева на экране кнопка **🛠**. Ребёнок её не видит.

| Кнопка | Что делает |
|---|---|
| ✈ Полёт (или клавиша **F**) | летать: WASD / стик, вверх — Пробел или E, вниз — Shift или Q, на планшете ▲ ▼ |
| ⚡ Скорость | 60 или 200 студов в секунду: до полян лететь далеко, они за 2600 студов |
| ⭐ +100 / ⭐ +1000 | звёзды на счёт — проверять магазин |
| ➜ Площадь, ➜ Мой дом, ➜ поляны | перенос; идущее занятие при этом обрывается |

Если панели нет — в Output не должно быть ошибок про `DevController`.

### 3.1. Площадь и порталы

- [ ] Порталы — **круглые каменные врата**: камни по кругу, каждый четвёртый светится
      цветом мира, внутри светящийся диск с крутящимся вихрем, искры и свет вокруг.
      Вокруг врат медленно облетают буквы «А Б В Г Д Е» (мир букв) и «1 2 3 4 5 +»
      (мир математики). Над верхним камнем — табличка «Уровень N из 11».
- [ ] Войти в портал можно только сквозь диск; постамент ничего не запускает.
- [ ] У мира букв стопки **кубиков с буквами**, у мира математики — **с цифрами**:
      два кубика внизу, один сверху, знак на каждой грани. Такие же стопки
      в парке и на полянах занятий, буквы у разных стопок разные.

- [ ] Игрок появляется на площади лицом к двум порталам, не проваливается сквозь пол.
- [ ] В центре два портала: синий **📖 МИР БУКВ** и оранжевый **🔢 МИР МАТЕМАТИКИ**.
      Оба горят и оба работают.
- [ ] Полукругом перед порталами семь падов: 🏃 Полоса препятствий, 🌧 Буквопад,
      🪜 Алфавитная лестница, 🫧 Пузыри, 🪞 Зеркало, ⚖️ Весы, 🛍 Магазин. Между ними проход.
- [ ] Подойти к паду — появляется подсказка с кнопкой (**E** на клавиатуре, тап на телефоне).
- [ ] Над аркой каждого портала табличка: над синим «Уровень 1 из 11 · Первые три»,
      над оранжевым «Уровень 1 из 11 · Полянка счёта». После финиша уровня синяя меняется
      на «Уровень 2 из 11 · Гости».
- [ ] **Над головой нет травы, в небе нет цветных кубов**, под ногами площадь.
- [ ] Встать на платформу портала — **ничего не происходит**. Пройти сквозь
      светящуюся арку синего портала → начинается забег. Если забег был не закончен,
      он **продолжается**
      с последней арки (см. 3.6).
- [ ] Оранжевый портал → начинается забег с числами (см. 3.6.1).
- [ ] За краем площади кольцо деревьев, в дальней половине — фонтан с лавочками
      и фонарями, у выходов на дорожки — клумбы. Пока моделей художника нет, это
      **эскизы из примитивов**: ёлка из шаров, лавочка из брусков
      ([21-DECOR.md](21-DECOR.md)).
- [ ] Небо с облаками, воздух с дымкой, у фонарей светятся плафоны.
- [ ] У каждой из четырёх клумб кружат по две бабочки, машут крыльями, сквозь них
      можно пройти. С деревьев за краем площади время от времени падают жёлтые
      и рыжие листья, ложатся на траву и тают. Ничего не мигает.
- [ ] На дешёвом телефоне кадр не проседает рядом с клумбой (сравнить с тем же местом,
      временно убрав `LiveWorldController.init()`).
- [ ] Ничто из декора не стоит на паде, перед порталом, на точке появления
      или на дорожке к домам.

### 3.1.1. Участки и дома

- [ ] По краю площади кольцо из **двадцати** участков, от площади к ним ведут
      четыре дорожки с фонарями по обе стороны.
- [ ] Между площадью и домами **парк, а не пустырь**: в каждой четверти роща,
      полянки с клумбами и лавочками, россыпь кустов и камней, перед домами —
      опушка из деревьев. Ни одно дерево не стоит на дорожке и у сундука.
- [ ] Дома **не стоят вплотную**: между соседними участками сад — куст, дерево,
      ещё дерево.
- [ ] Свободный участок — размеченная площадка с колышками и табличкой
      «Свободный участок». Не дырка в мире.
- [ ] На своём участке табличка с ником, а **за домом стоит Азбучная Башня**
      из 33 сегментов. В центре площади Башни нет.
- [ ] Вдоль фасада своего участка шесть падов: 🏠 Дом, 🔺 Крыша, 🌳 Двор, 🚧 Забор,
      🪑 Мебель, 🎈 Декор — с названием следующего уровня и ценой. Весь ряд
      помещается в участок, крайние пады не торчат за забор.
- [ ] Купить 🎈 Декор за 20 ⭐ на **пустом** участке (это самая дешёвая покупка
      в игре): над калиткой появилась гирлянда флажков. Дом для декора не нужен.
- [ ] Купить 🪑 Мебель без дома → пад сработал, ⭐ списались, но во дворе ничего
      не появилось. Купить 🏠 Дом → стол встал справа от дома. Мебель ждёт дом,
      как и крыша.
- [ ] **Пробежать по паду улучшения — ничего не покупает.** Нужно подойти
      и подержать кнопку: тратить накопленное на бегу нельзя.
- [ ] Хватает звёздочек → постройка появляется сразу, ⭐ в углу уменьшились.
      Не хватает → всплывает «Звёздочек пока не хватает», ничего не списывается.
- [ ] Подойти к **чужому** участку: подсказки улучшения там нет вовсе.
- [ ] Выйти и зайти снова: дом на месте, тот же участок или соседний — но с домом.

**Посмотреть все уровни, не копя шесть тысяч звёздочек.** В консоли Studio
(вкладка **View → Command Bar**, режим сервера):

```lua
require(game.ServerScriptService.Server.Services.BaseService).preview(3, {house=4, roof=4, yard=4, fence=4, furniture=4, decor=4})
```

Участок №3 покажет башенку со светящейся крышей, садом с фонтаном и буквенным
забором. Это только показ: ничего не покупается и ни у кого не отнимается.

- [ ] Справа от дома стол, кровать, коврик и полка — все четыре сразу: мебель
      набирается, а не заменяется. Слева качели, у дорожки фонарики, у угла шарики.
      Ничто не стоит внутри дома и не перекрывает пады.

Заработанное учёбой — флаги, арка и шпиль — показывается так же:

```lua
require(game.ServerScriptService.Server.Services.BaseService).preview(3, {house=4, roof=4, yard=4, fence=4}, {flags=11, arch=true, spire=true, mathFlags=11, countSpire=true})
```

- [ ] Вдоль **левого** забора 11 флагов с цифрами 1–11. У задней стены, правее
      фонтана, голубой шпиль с подписью «1 2 3 … 9». Ни во что не врезается.

- [ ] Вдоль правого забора 11 флагов разного цвета, на каждом буква ступени.
- [ ] Перед калиткой золотая арка «А Б В … И»; в правом заднем углу — золотой шпиль
      со звездой «33 из 33». Ничего не врезается в дом, кусты и фонтан.
- [ ] Пройти уровень в портале и вернуться домой → на своём участке стоит новый флаг.

**Комнаты букв и цифр** (docs/15-HOME-BASE.md § 5). Их не покупают: комната
появляется за освоенную букву и за освоенную ступень счёта.

```lua
require(game.ServerScriptService.Server.Services.BaseService).preview(3, {house=4, roof=4, yard=4, fence=4, furniture=4, decor=4}, {flags=11, arch=true, spire=true, mathFlags=11, countSpire=true, letterRooms={"a","b","v"}, mathRooms={"count_group"}})
```

- [ ] За домом слева пристройка «Комнаты букв»: на полке три плитки — А, Б, В,
      каждая своего цвета. Справа «Комнаты цифр» с плиткой «1».
- [ ] Стен три, крыши нет: полку видно с дорожки, заходить внутрь не нужно.
- [ ] Пристройки не врезаются ни в дом, ни в Башню, ни в шпили по углам.
- [ ] Снести дом (`house=0`) → комнат нет вовсе: пристраивать их не к чему.
- [ ] Нажать на плитку А в комнате букв → в Output запрос `letter_a`, плитка
      на миг вдавилась. Плитка «1» в комнате цифр → `num_1`.
- [ ] **Флаги ступеней на крыше.** В `preview` передать `stageFlags={1,2,3}`
      вместе с `roof=2` → на краях крыши три флажка с буквами А, Г, Ж
      (первые буквы ступеней). Без крыши (`roof=0`) флагов нет.

### 3.1.2. Сундуки в парке

- [ ] В Output `[Chests] сундуков в парке: 3`.
- [ ] За кольцом деревьев, между дорожками к домам, стоят три деревянных сундука
      с золотым замком. Ни один не стоит на дорожке и не врезается в дерево.
- [ ] Подойти и коснуться сундука → крышка откидывается, замок пропадает,
      «🗝 Сундук! 🍄 Шляпка-мухомор — теперь твоя!», шляпка сразу на голове,
      в Output `[Chests] … открыл chest_pines`. Звёздочки **не** прибавились.
- [ ] Постоять рядом → ничего не повторяется. Нажать подсказку «Открыть» ещё раз →
      «Этот сундук ты уже нашёл», вторая шляпка не появилась.
- [ ] Отойти далеко и вернуться → крышка у открытого так и откинута.
- [ ] Второй игрок видит этот же сундук **закрытым**, пока не откроет сам.

### 3.2. Буквопад

- [ ] Пад **🌧 Буквопад** → отсчёт → поляна «Поляна Буквопада»: поле в пять цветных
      дорожек, облако над ним, за полем табло с буквой-целью.
- [ ] Из облака падают шарики с буквами, под каждым на траве растёт тень.
- [ ] Упавшая буква пару секунд прыгает на траве, потом тает.
- [ ] Добежать до **своей** буквы и коснуться: искры, счётчик растёт, в Output `+1 ⭐`.
- [ ] Постоять под падающей буквой: пока она высоко, ничего не происходит.
- [ ] Коснуться **чужой** (или тапнуть): счётчик **не падает**, буквы на секунду
      притухают и не ловятся. Тап по своей тоже засчитывается.
- [ ] Поймать 5 целевых → испытание закрывается, в Output итог со звёздами и наградой.
- [ ] Счётчик ⭐ в правом верхнем углу вырос.

**Главное, что здесь проверяется:** нельзя пройти испытание, тыкая подряд всё
без разбора. Попробуй специально — должно быть медленно и неудобно.

### 3.3. Магазин

- [ ] Пад **🛍 Магазин** (или кнопка 🛍 справа внизу) → открывается витрина.
- [ ] Карточки отсортированы от дешёвых к дорогим, цена продублирована звёздочками.
- [ ] Недоступное подписано **«ещё N ⭐»**, а не замком.
- [ ] В витрине 62 вещи, прокручивается.
- [ ] **Аксессуары каталога.** Купить и надеть по очереди: кепку (теперь настоящая
      кепка Roblox), заячьи уши, рюкзак-собачку, очки-ромашки. Каждая вещь появилась
      на персонаже целиком, сидит на своём месте, **своя одежда и причёска
      персонажа не пропали**. Надеть уши, потом ковбойскую шляпу → уши сменились
      шляпой, а не остались обе. «Снять» → вещь пропала.
- [ ] Пройтись по всем 23 новым вещам: если какая-то не появилась на персонаже
      и в Output `[Cosmetics] аксессуары каталога не надеты` — вещь сняли
      с продажи, её номер надо заменить в `Config/Shop`.
- [ ] Прокрутить дальше. Примерить новые: цилиндр и шапка
      с помпоном сидят на голове, а не в ней; воздушный шарик висит над плечом
      на ниточке; звёздные очки на глазах; бандана на шее, а не на лбу. Среди дорогих — ледяные, золотые
      и огненные буквята; радужные подписаны «☀ 30 дней». В конце — Солнечная шляпа и
      Солнечные зайчики: под ними «☀ 7 дней» / «☀ 14 дней», кнопка «🔥 0 из 7»
      серая, нажатие ничего не покупает. Там же мухомор, ёжик и «Листопад»
      с подписью «🗝 в сундуке» и серой кнопкой «Найди в парке». Дешевле 25 ⭐ — кепка, бантик, венок,
      колпак звездочёта, усы.
- [ ] Шлем космонавта прозрачный: лицо под ним видно.
- [ ] Купить кепку за 10 ⭐ → баланс уменьшился, кнопка стала **«Надеть»/«Снять»**.
- [ ] **Кепка сразу появилась на голове персонажа.**
- [ ] Тап по «Снять» → предмет пропал с персонажа; ещё раз → вернулся.
- [ ] Закрыть магазин крестиком.

### 3.4. Башня

- [ ] Сегменты букв, которые уже ловил, стали цветными (тусклый → яркий по мере прогресса).
- [ ] Клик по сегменту — в Output предупреждение об отсутствии озвучки
      вида `letter_m` (значит, реплика запрошена правильно; когда файлы появятся,
      буква назовёт себя).

### 3.5. Алфавитная лестница

- [ ] Встать на пад **🪜 Алфавитная лестница** → над ним отсчёт 3 · 2 · 1, экран гаснет,
      ребёнок на поляне «Гора Алфавита». Сойти с пада во время отсчёта → ничего не запустилось.
- [ ] Перед ребёнком вся гора: **не меньше пяти ступеней**, на первой указатель с буквой,
      на остальных «?», на вершине флаг и серая звезда. Гора не упирается в задник.
- [ ] На первой ступени лежат плиты с буквами, над ними таблички. Подсказка
      «Какая буква идёт после А? Встань на неё!».
- [ ] Встать на неверную плиту → она проседает и возвращается, преграда стоит.
- [ ] Встать на верную → «?» на следующей ступени стал буквой, преграда исчезла,
      на ступень можно зайти шагом, без прыжка.
- [ ] Новичок (открыта одна ступень, 3 буквы): после В гора идёт дальше — Г, Д…,
      у этих ступеней верная плита светится сразу.
- [ ] Обойти гору сбоку и запрыгнуть на верхние ступени нельзя.
- [ ] Последняя плита → звезда на вершине загорелась и искрится, на экране
      «Ты на вершине! А Б В Г Д Е». Через ~4 секунды итог и возврат к паду.

### 3.5.1. Пузыри и Зеркало

- [ ] Пад **🫧 Пузыри** → впереди всплывают прозрачные шары с буквами, сверху цель
      и счётчик. Доплыв доверху, пузырь снова появляется внизу.
- [ ] Лопнуть **нужный** → вспышка, счётчик растёт. **Не тот** → пузырь становится
      оранжевой рыбкой 🐟 и уплывает, остальные на секунду притухают.
- [ ] Лопнуть все нужные → итог со звёздами.
- [ ] Пад **🪞 Зеркало** → ряд белых табличек с одной буквой: одна правильная,
      остальные вверх ногами, на боку или отражены (R вместо Я, N вместо И).
      **Букву-цель сверху не показывают** — только счётчик.
- [ ] Выбрать правильную → таблички гаснут, через секунду следующий раунд.
      Неправильную → таблички притухают, раунд остаётся.
- [ ] Ни в одном раунде нет таблички, которая неотличима от правильной
      (О на боку, Н вверх ногами).

### 3.5.1.1. Весы

- [ ] Пад **⚖️ Весы** → отсчёт → поляна «Двор Весов». Порталов и падов рядом нет,

      светящийся золотой шар над осью, чаши висят на цепях. На одной чаше голубые
      камни, вторая пустая, весы наклонены к камням. Ближе к персонажу 2–3 деревянных
      ящика с бортиками, в каждом кучка камней своего цвета. Цифр нигде нет.
- [ ] Коснуться кучки, где камней **столько же** → на пустой чаше камни **того же
      цвета**, что и кучка, весы выровнялись, от оси летят искры, внизу «3 = 3»,

- [ ] Цепи всё время соединяют концы коромысла и чаши, и когда весы качаются.
- [ ] Коснуться кучки **с другим** количеством → весы качнулись к тяжёлой чаше,
      через секунду камни сняты и весы вернулись. Кучки на месте, в паузу
      касания не срабатывают.
- [ ] Весы не толкают персонажа и сквозь них можно пройти: всё закреплено, без физики.
- [ ] Пройти все раунды → итог со звёздами. На новом профиле камней не больше трёх.

      Ещё две → над головой столбик из трёх, наверху «🍓🍓🍓». Цифр нет.
- [ ] Принести **столько, сколько сказал голос** → ягоды упали в корзинку, искры,
      в Output `+⭐`, через пару секунд новые ягоды и новое задание.
- [ ] Принести **больше** → «Посчитаем ещё раз!», ягоды вернулись на кусты,
      задание звучит снова, на секунду ягоды не срываются.
- [ ] Ребёнок на ступени сложения: наверху пример «2 + 1», собрать надо ответ.
      На составе числа в корзинке уже лежат ягоды — доложить до нужного.

### 3.5.2. Буква дня

- [ ] За порталами, в просвете между арками, камень с золотым кристаллом.

- [ ] Встать на кристалл → Буквопад, цель — буква с камня. Закончить →

- [ ] Снова на камень → Пузыри с той же буквой. Потом Зеркало: **все раунды**

- [ ] Ещё раз на камень → «Буква дня уже пройдена. Приходи завтра!», задание не начинается.

### 3.6. Забеги: туннель и полоса препятствий

- [ ] Пройти сквозь арку синего портала **📖 МИР БУКВ**. Игрока телепортирует в коридор.
- [ ] Внизу по центру появляются **субтитры**: «Беги в ворота вот с этой буквой!»,
      «Буква А». Пока озвучки нет, так видно всё, что говорит голос.
- [ ] Коридор перегорожен воротами: над проёмами буквы, стены между ними сплошные.
      Объехать выбор нельзя.
- [ ] Верные ворота → счётчик растёт, в Output `+1 ⭐`.
- [ ] Неверные → персонаж заметно замедляется на секунду, ничего не отнимается.
- [ ] Между воротами стоят препятствия: барьеры, ямы, низкие своды, балки, ступени.
      **Ни одно не стоит вплотную к воротам** — под ними всегда ровный пол.

**Средние элементы** (появляются, когда сложность дорастёт до третьего уровня:
несколько удачных забегов подряд, см. [19-OBSTACLES.md](19-OBSTACLES.md) § 3.2).
Быстрее всего проверить их так: в Studio выставить профилю
`difficulty.obstacle_course = 5` и зайти на полосу.

- [ ] Маятник качается поперёк своей дорожки медленно, соседние дорожки свободны,
      и рядом с шаром в крайней точке можно спокойно пройти.
- [ ] Платформа ездит над ямой; яма при этом такая же короткая, как обычная, —
      её можно просто перепрыгнуть и платформу не ждать.
- [ ] Исчезающие плиты гаснут по очереди. **Две подряд не гаснут никогда** —
      дорожка не превращается в сплошную яму.
- [ ] Батут подбрасывает вверх и не бьёт о потолок.
- [ ] На льду заносит, но падать с него некуда.
- [ ] Кочки: три серых камня через яму в одной дорожке, по ним можно пропрыгать.
- [ ] Сложный ряд (выставить `difficulty.obstacle_course = 5`): бревно крутится
      поперёк дорожки и перепрыгивается; розовый поршень медленно выезжает из стены
      в **крайнюю** дорожку и уезжает; зелёная стена-гребёнка с узкой щелью
      в каждой дорожке.
- [ ] Новые элементы сложного ряда: **карусель** — низкий диск с четырьмя
      перекладинами, крутится медленно, перекладину можно перешагнуть или
      переждать; **подъёмник** — голубая площадка едет вверх к мостику, с мостика
      спрыгиваешь дальше по дорожке, падать при этом на обычный пол;
      **спираль** — ступени по кругу вокруг столба, поднимают и опускают обратно.
- [ ] Ни один элемент не стоит вплотную к воротам — перед воротами ровный пол.
- [ ] На первых уровнях встречаются **горка** (зелёный пологий подъём во всю ширину
      с флажком, забегается без прыжка) и **слалом** (оранжевые конусы змейкой
      в одной дорожке: между ними можно петлять или обойти).
- [ ] **Препятствия не выглядят брусками**: у барьера белые стойки и полосы, у ямы
      полосатые кромки и оранжевые конусы, у свода колонны и светящаяся кромка снизу,
      у балки фонарики на концах, у ступеней белые кромки, у гребёнки золотые шапки.
      Сквозь отделку можно пройти, прыгать и бежать так же, как раньше.
- [ ] **Сохранка — арка**: мраморные столбы с шарами, перекладина, справа флагшток
      с серым флагом внизу. Пробежать → флаг взлетает наверх, зеленеет, искры.
      Продолженный забег: пройденные арки уже с поднятыми зелёными флагами.
- [ ] **Особый участок.** На одном из средних отрезков мира букв перед воротами
      лестница: табличка «А → ?», плиты с буквами на полу, прозрачная преграда перед
      первой ступенью. Встать на неверную плиту → голос называет букву, замедление,
      верная плита засветилась. Встать на верную → преграда исчезла, на указателе
      ступени буква, +1 ⭐. После верхней ступени — горка вниз, дальше ворота.
- [ ] Выйти после этого отрезка и зайти снова: лестница стоит, но без плит и преград.
- [ ] **Отрезок между сохранками бежится около тридцати секунд**, а не трёх-четырёх
      (docs/14-TUNNEL-MODE.md § 3.4). Проверять секундомером от арки до арки:
      на первом уровне в отрезке связки паркура чередуются с пробежками,
      на последних пробежек нет совсем — сплошной паркур.
- [ ] Весь уровень мира букв занимает 3–5 минут, а не меньше минуты.
- [ ] На одном отрезке между воротами живых элементов (маятник, платформа, плиты)
      **не больше двух**.
- [ ] Между препятствиями висят пары плиток с буквами: буква этого отрезка
      и ещё одна. Пробежать через **свою** — звон, +1 ⭐, плитка исчезла.
      Через чужую — ничего, счётчик ворот наверху не меняется.
- [ ] Прямо перед воротами плиток нет никогда.
- [ ] На одном из отрезков в крайней дорожке — каменный постамент с искрящейся
      золотой буквой. Запрыгнуть и коснуться → звон, в Output `нашёл секрет уровня … +15 ⭐`
      и запрос названия буквы. Пройти этот уровень ещё раз → секрета уже нет.
- [ ] Сразу за каждыми воротами — арка-сохранка. Пробежал через неё — флаг зазеленел.
- [ ] Свалиться в яму → мягко приземлиться внизу и оказаться у последней сохранки.
      Звёздочки и пройденные ворота при этом **не теряются**.
- [ ] Финишная арка → испытание закрывается, игрок стоит **рядом** с порталом,
      лицом к нему, а не на нём. Забег сам по себе снова **не начинается**.
- [ ] Пад **🏃 Полоса препятствий** → то же самое, но препятствий заметно больше,
      а ворот меньше.

**Сохранка переживает выход из игры** (docs/14-TUNNEL-MODE.md § 3.3).
Проверять только в опубликованном месте с включённым доступом к API: в Studio
без публикации профиль живёт в памяти и до перезапуска не доживает.

- [ ] Пройти в туннеле хотя бы одну арку-сохранку и **выйти из игры**, не добежав
      до финиша (кнопка 🏠 или просто закрыть клиент).
- [ ] Зайти снова, встать на тот же пад. Игрок оказывается **у той же арки**,
      а не на старте, и туннель тот же самый: те же буквы над проёмами, те же
      препятствия. Флаги пройденных арок горят зелёным сразу.
- [ ] Пройденные ворота второй раз не спрашиваются: счётчик уже показывает
      пройденное, а повторный проход через них ничего не начисляет.
- [ ] Добежать до финиша → следующий запуск строит **новый** забег, а не тот же.

**Уровни мира букв** ([14-TUNNEL-MODE.md](14-TUNNEL-MODE.md) § 3.3). Туннель
за синим порталом — это уровень, и буква у каждого отрезка своя.

- [ ] Новый профиль → синий портал. Отрезков четыре, в воротах **по два проёма**,
      над ними только А, Б и В. **Б и В ни разу не стоят в одних воротах.**
- [ ] Первые три отрезка спрашивают А, потом Б, потом В; четвёртый — одну из них
      повторением. Сверху на HUD буква меняется сразу после ворот, всплывает
      «Теперь беги в ворота с буквой …».
- [ ] Буква, с которой ребёнок ещё не встречался, появляется крупно на экране
      в момент смены — как на старте забега.
- [ ] Нарочно пробежать в неверный проём → буква следующего отрезка всё равно
      объявляется и появляется сверху.
- [ ] Добежать до финиша → в итоге «Уровень «Первые три» пройден!». Снова в портал →
      уровень «Гости»: отрезков четыре, буквы Г, Д, Е, повторение — с первой ступени.
- [ ] Выйти посреди уровня и вернуться → тот же уровень с той же арки, а наверху
      буква невзятого отрезка, а не первого.

Уровни идут по финишу, а не по статусам букв: пройти уровень можно и с ошибками.
Посмотреть поздний уровень быстрее всего, выставив профилю `levels.letters = 6`
в Studio — портал поведёт на седьмой.

### 3.6.1. Ворота с числами

- [ ] **Весы особого участка.** На одном из средних отрезков мира математики перед
      воротами над трассой весы на двух столбах: на левой чаше голубые камни, коромысло
      наклонено, под ним прозрачная преграда. На полу 2–3 кучки разного цвета.
- [ ] Встать на кучку с другим количеством → весы качнулись и вернулись, голос называет
      число кучки, замедление, верная кучка засветилась.
- [ ] Встать на верную → камни того же цвета на правой чаше, весы ровные, преграда ушла,
      +1 ⭐ и число голосом. Дальше второй раунд, потом ворота.

Тот же коридор, но над проёмами числа, и **задача у каждых ворот своя**
([16-MATH.md](16-MATH.md) § 3.1).

- [ ] Задание видно субтитром внизу: «Беги на цифру три», «Сколько будет два плюс два».

- [ ] Оранжевый портал **🔢 МИР МАТЕМАТИКИ** → **Войти**. Игрока телепортирует
      в такой же коридор с воротами.
- [ ] Над проёмами числа, под ними — **столько же шариков, сколько написано**
      (на ранних ступенях; на поздних шарики убраны).
- [ ] Пробежал верные ворота → счётчик растёт, в Output `+1 ⭐`; неверные →
      замедление на секунду и ничего не отнято.
- [ ] После **любых** ворот — и верных, и неверных — звучит и появляется сверху
      задача **следующих** ворот, а не повторяется пройденная.
- [ ] Сверху на HUD виден пример («2 + 2»), если он есть. На заданиях вроде
      «беги на цифру три» **сверху пусто — и это правильно**: ответ ребёнок должен
      посчитать, а не найти такую же картинку.
- [ ] На ступени «равные группы» и «умножение» над воротами висят тарелки
      с предметами: их можно пересчитать.
- [ ] Выйти из забега, не добежав до финиша, и войти снова → тот же туннель
      с **теми же задачами**, с последней арки.

Уровень счёта — это путь: финиш открывает следующий, как в мире букв.
Посмотреть поздний быстрее всего, выставив профилю `levels.math = 6` в Studio —
портал поведёт на седьмой («Сложение»). После финиша в итоге строка
«Уровень «Полянка счёта» пройден!», а табличка над порталом сменится.

### 3.7.1. Обучение первых минут

Проверять на **новом** профиле: в Studio без публикации он новый при каждом Play.

      от ног персонажа к паду тянется светлая полоса. В Output — запрос `story_intro`.
- [ ] Пройти Буквопад → через пару секунд стрелка и полоса переезжают к **🛍 Магазину**,
      в Output — запрос `ui_shop` и строка `[Tutorial] … шаг «catch» сделан`.
- [ ] Купить шапку → стрелка над **синим порталом**.
- [ ] Пройти первый уровень до финиша → стрелки больше нет.
- [ ] В туннеле полосы не видно, над площадью стрелка остаётся.
- [ ] Новый профиль, но пойти **сразу в портал**, мимо Буквопада → после финиша
      стрелка всё равно зовёт в Буквопад, а в портал больше не зовёт.
- [ ] ⚙ → PIN → на «Главном» кнопка **«Пропустить обучение»** → стрелка исчезает,
      кнопка пропадает.

### 3.7.2. Буквята

Освоить букву по-честному можно только через два дня, поэтому в Studio буквёнка
выдаём из командной строки (**View → Command Bar**, режим сервера):

```lua
local S=game.ServerScriptService.Server.Services local M=require(game.ReplicatedStorage.Shared.Logic.MasteryRules) local p=game.Players:GetPlayers()[1] require(S.ProfileService).update(p,function(pr) local x=M.newProgress(os.time()) x.mastery=3 x.correct=5 pr.letters.m=x end) require(S.PetService).grant(p,"m")
```

- [ ] Появляется крупная М на экране и надпись «Новый друг — буквёнок М!», звенит награда.
- [ ] За правым плечом персонажа летает **зверёк** цвета буквы с буквой М над головой:
      животик, розовые щёчки, глаза с бликами, лапки и хвостик. Покачивается,
      раз в несколько секунд моргает. Не толкается, в стенах не застревает.
- [ ] У разных букв разные зверьки: А — котик (уши, усы), Б — зайчик (длинные
      уши шевелятся), В — мишка (круглые уши, нос), Г — птенчик (клюв, машет
      крыльями), Д — лягушонок (глаза сверху, улыбка), дальше по кругу.
- [ ] Ответить верно в любом занятии → буквёнок подпрыгивает с оборотом, из него искры.
- [ ] Радужный скин перекрашивает и уши, и лапки, и хвост, а не только тело.
- [ ] Прыгнуть в портал → буквёнок оказывается рядом сразу, а не летит через весь мир.
- [ ] Нажать на буквёнка → в Output запрос `letter_m`, буквёнок подпрыгивает.
- [ ] Выдать ещё одну букву (заменить `m` на `a` в строке выше) → буквёнок М
      **остаётся**. Коснуться А на Башне → за персонажем теперь буквёнок А.
- [ ] Коснуться на Башне **неосвоенной** буквы → буквёнок не меняется.

**Второй слот и Хранитель.** Освоить сразу первые 9 или все 33 буквы:

```lua
local S=game.ServerScriptService.Server.Services local M=require(game.ReplicatedStorage.Shared.Logic.MasteryRules) local L=require(game.ReplicatedStorage.Shared.Config.Letters) local p=game.Players:GetPlayers()[1] local N=9 require(S.ProfileService).update(p,function(pr) for i,id in L.ordered() do if i<=N then local x=M.newProgress(os.time()) x.mastery=3 pr.letters[id]=x end end end) require(S.PetService).grant(p,L.ordered()[N])
```

- [ ] `N=9` → один буквёнок. Затем `N=10` → «Теперь с тобой летают два буквёнка!»,
      второй буквёнок за **левым** плечом.
- [ ] Коснуться на Башне третьей освоенной буквы → она за правым плечом, прежний
      правый переехал за левое.
- [ ] `N=33` → через несколько секунд «👑 Все 33 буквы! Ты — Хранитель Азбуки!»,
      над головой золотая надпись. Перерождение (сброс персонажа) её не снимает.
- [ ] ⚙ → «Начать заново» → надпись и буквята пропадают.

**Скины буквят.** Дать звёздочек и купить:
`require(game.ServerScriptService.Server.Services.ProfileService).update(game.Players:GetPlayers()[1], function(p) p.stars = 3000 end)`.

- [ ] Купить «Золотые буквята» → буквята стали золотыми, на месте, а не прилетели заново.
      Буква над головой осталась цвета буквы.
- [ ] «Снять» → буквята снова цвета своих букв. «Огненные» → оранжевое свечение.
- [ ] Радужные: выставить `p.daily.best = 29`, `streak = 29`, пройти букву дня →
      буквята медленно переливаются, без мигания.

### 3.8. Родительский режим

Подробности — [13-PARENT-MODE.md](13-PARENT-MODE.md) § 9.

- [ ] Слева вверху, под меню Roblox, маленькая серая ⚙. Нажать → «Этот раздел —
      для взрослых» и вопрос вида «Сколько будет 7 × 8?».
- [ ] Неверный ответ → «Не то. Вот другой вопрос:» и **новый** вопрос.
- [ ] Верный ответ на новом профиле → «Придумайте PIN из 4 цифр». Вместо цифр
      на экране точки. Повторить PIN с ошибкой → «PIN не совпали», начать заново.
- [ ] PIN совпал → сразу отчёт. Вкладки «Главное», «Советы», «Подробно», «Дома»
      переключаются мгновенно. Внизу «Главного» — строка про микрофон.
- [ ] Закрыть ✕ и открыть снова → опять взрослый вопрос, потом «Введите PIN».
- [ ] Неверный PIN → «Осталось попыток: 4», и так до пятой. После пятой —
      «Подождите 60 с». Через минуту снова можно.
- [ ] «Забыли PIN?» → «Сбросить» → снова «Придумайте PIN». Звёздочки и буквы
      ребёнка на месте.
- [ ] В Output при задании и сбросе PIN — строка `parent_setting_change`,
      **самого PIN в ней нет**.

**Лимит времени.** В Studio сутки начинаются с нуля при каждом Play, поэтому
проще всего выставить самый короткий лимит и подождать 15 минут, либо
временно поменять `PlayLimit.OPTIONS` на `{ 1 }`.

- [ ] ⚙ → PIN → вкладка «Настройки»: «Сегодня сыграно N мин», кнопки
      «Выкл / 15 / 20 / 30 / 45 мин». Выбранная подсвечена.
- [ ] Время вышло **посреди забега** → забег не обрывается. После финиша —
      экран с луной «На сегодня всё!» и запрос `ui_goodbye` в Output.
- [ ] «Хорошо 👋» → экран уходит, по площади можно гулять, магазин открывается.
      Подойти к паду → экран появляется снова, занятие не начинается.
- [ ] «⚙ Для родителей» прямо на экране → поднять лимит до 45 → экран уходит сам.
- [ ] «Забыли PIN?» → «Сбросить» → лимит **остался** прежним.
- [ ] «Настройки» → «Звук»: у голоса кнопки 25–100 %, у музыки и эффектов «Выкл»–100 %.
      Голос 25 % → музыка и эффекты сами встали на 25 %, музыка в игре стала тише.
- [ ] Музыка 100 % при голосе 50 % → подсветилась 50 %.
- [ ] Субтитры «Вкл» → в Output строка `parent_setting_change … subtitles on`.
- [ ] «Покупки за Robux» → «Скрыть» → в Output `parent_setting_change … hide_robux on`.
      Открыть магазин ребёнком: витрина за ⭐ на месте целиком, карточек за Robux
      нет ни одной (сейчас таких предметов в каталоге нет, поэтому витрина
      не меняется — это правильно). Вернуть «Показывать» → всё как было.
- [ ] «Сбросить прогресс буквы»: кнопки только у букв, которыми занимались.
      Нажать А → «Сбросить прогресс буквы А?» → «Сбросить» → кнопки А больше нет,
      сегмент А на Башне потускнел, звёздочки на месте.
- [ ] «Начать заново…» внизу «Настроек» → список «Сотрётся / Останется» → «Дальше» →
      «Введите PIN, чтобы начать заново». Неверный PIN → «Осталось попыток: 4».
- [ ] Верный PIN → «Обучение начато заново». Башня тусклая, буквёнка нет, флаги во дворе
      пропали, над синим порталом «Уровень 1 из 11». Звёздочки, шапка и дом на месте,
      в Output `parent_setting_change … profile_restart`.
- [ ] То же посреди забега (открыть ⚙ в туннеле) → забег закрылся, персонаж у дома.
- [ ] Напоминание об отдыхе: через 20 минут игры всплывает «Давай отдохнём?»,
      в Output запрос `ui_rest_reminder`. Во время забега — не звучит, ждёт финиша.

## 4. Известные ограничения (это не баги)

| Что | Почему |
|---|---|
| Полная тишина | Озвучка не записана. Игра запрашивает реплики и пишет предупреждения в лог |
| Прогресс не сохраняется между запусками | DataStore недоступен в неопубликованном месте, профиль живёт в памяти |
| Всё серое и угловатое | Арта нет, это серый ящик: проверяются тайминги и логика, не красота |
| Декор — эскизы из шаров и брусков | Моделей художника ещё нет ([21-DECOR.md](21-DECOR.md) § 7) |

### Включить настоящие сохранения

1. **File → Publish to Roblox As…** — опубликовать место.
2. **Home → Game Settings → Security** → включить **Enable Studio Access to API Services**.
3. Перезапустить Play. В логе пропадёт предупреждение о работе в памяти.

## 6. Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| `rojo : Имя "rojo" не распознано` | PATH не подхватился — закрыть и открыть консоль заново |
| В Studio нет вкладки Rojo | Плагин не установлен: положить `Rojo.rbxm` из релизов rojo-rbx/rojo в `%LOCALAPPDATA%\Roblox\Plugins` и перезапустить Studio |
| Connect не находит сервер | Не запущен `rojo serve` либо закрыта его консоль |
| Output пустой | Скрипты идут только в **Play**, не в режиме редактирования |
| В Explorer нет `ReplicatedStorage.Shared` | Синхронизация не прошла — переподключить Rojo (Disconnect → Connect) |
| Изменил `default.project.json`, ничего не поменялось | Правки файла проекта требуют перезапуска `rojo serve` |
| Игрок спавнится не на площади | Перезапустить Play: чужие точки появления выключаются на старте сервера |
